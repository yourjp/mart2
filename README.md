# Mart app 2 - 마트 장보기 예산 계산기 웹 앱 2

마트에서 장을 볼 때 모바일 브라우저로 물건 가격을 빠르게 입력하고, 현재 총액과 예산 대비 남은 금액 또는 초과 금액을 즉시 확인할 수 있는 웹 앱입니다.

---

## 🌟 주요 기능

1. **상단 전광판 (Dashboard)**
   - 현재 총합계 및 예산 대비 남은 금액 / 초과 금액 실시간 표시
   - 현재 선택된 마트의 월 예산 대비 누적 지출률을 전광판 좌측 중간에 세로 그래프와 `%`로 표시
   - 예산 범위 내: 이마트(파란색) / 코스트코(청록/에메랄드) 마트별 테마
   - 예산 초과 시: 고대비 빨간색 경고 테마 자동 전환

2. **빠른 가격 축약 입력 규칙**
   - 한 자리 (`1`) ➡️ `1,000원`
   - 두 자리 (`10`) ➡️ `10,000원`
   - 세 자리 이상 (`990`, `1200`) ➡️ 원본 원 단위 금액 (`990원`, `1,200원`)
   - 소수점 (`4.8`) ➡️ `4,800원`, (`.5`) ➡️ `500원`
   - 실시간 입력 해석 안내 문구 표시 (`10,000원으로 입력됩니다`)

3. **가격 변화 판정 & 이력 관리 (`priceHistory`)**
   - 동일 품목의 새 가격 입력 시 이전 가격과 비교하여 `할인`, `인상`, `동일`, `첫 기록` 배지 표시
   - 품목별 최신 20개 가격 이력 (`priceHistory`) 및 `lastPrice` 자동 저장

4. **품목명 자동완성 & 추천**
   - 한 글자 입력 또는 초성 검색(예: `ㄱ` ➡️ `계란`, `깻잎`, `콩국물`) 지원
   - 저장된 최근 가격 함께 표시 (`맥주 · 최근 12,000원`)
   - 추천 품목 선택 시 품목명과 최신 가격 자동 채우기

5. **예산 초과 시 품목 추천 배너**
   - 총합이 예산을 초과하면 초과 금액과 가장 가까운 품목 1개를 자동 탐색하여 제안
   - **"이 품목 빼기"** 버튼 클릭 한 번으로 빠르게 수량 조절/삭제 가능

6. **마트별 (이마트 / 코스트코) 독립 데이터 관리**
   - 상단 탭으로 `이마트`와 `코스트코` 간 용이한 전환
   - 마트별로 예산, 장바구니, 저장 품목, 가격 이력이 독립적으로 관리

7. **구매내역 저장 및 조회**
   - **"장바구니 저장"** 버튼 클릭 시 `POST /api/save-record`로 구매내역을 Neon Postgres에 저장
   - **"구매내역"** 모달에서 월간/연간/전체 구매내역과 월간/연간 랭킹을 조회
   - 모바일에서는 조회 필터가 2줄로 배치되고, 긴 구매내역은 모달 내부에서 스크롤

8. **가계부**
   - **"가계부"** 모달에서 선택 월 기준 전체/이마트/코스트코 지출, 예산 잔여/초과, 지난달 대비, 연간 누적을 확인
   - 월 표시 라벨은 `2026년 8월` 형식으로 표시

9. **품목 MD 및 영수증 JSON 업로드**
   - **"품목 MD 업로드"**로 마트별 품목/단가 Markdown 파일을 업로드
   - **"품목 MD 다운로드"**로 현재 품목 데이터를 내려받기
   - **"영수증 JSON 업로드"**로 변환된 영수증 JSON을 구매내역 DB에 저장 전 미리보기
   - **"receipt.md 저장" / "receipt.md 다운로드"**로 Neon DB 기준 영수증 변환 규칙을 갱신하거나 내려받기

---

## 💾 데이터 저장 방식

- 현재 기준 저장소는 **Neon Postgres**입니다.
- `DATABASE_URL` 환경 변수로 DB에 연결하며, 품목, 가격 이력, 예산, 장바구니, 구매내역을 서버 API로 관리합니다.
- 브라우저 `localStorage`는 예산, 장바구니, 등록/추천 품목, 가격 이력 저장소로 사용하지 않습니다.
- Vercel 서버리스 환경에서는 로컬 Markdown 파일의 영구 저장을 보장하지 않으므로 구매내역의 기준 저장소는 DB입니다.

## 🛠️ 설치 및 로컬 실행 방법

### 요구사항
- Node.js v18 이상
- npm

### 1. 패키지 설치
```bash
npm install
```

### 2. 서버 실행
```bash
npm start
```
서버 실행 후 브라우저에서 `http://localhost:3000`으로 접속합니다.

## 🚀 Vercel 배포 가이드

본 프로젝트는 `vercel.json` 설정을 포함하고 있어 Vercel에 손쉽게 배포할 수 있습니다.

1. GitHub 저장소에 코드를 푸시합니다.
2. [Vercel Dashboard](https://vercel.com)에서 **Import Project**를 선택합니다.
3. Framework Preset을 **Other** 또는 **Node.js**로 설정하고 배포(Deploy)를 진행합니다.
4. 배포 완료 후 제공되는 Vercel URL 접속 시 동일하게 이용 가능합니다.

## 📁 프로젝트 구조

```text

├─ package.json        # Node.js 패키지 정보 및 의존성

├─ .gitignore         # git 제외 파일 설정 (node_modules, 구매내역.md 등)

│  ├─ index.html      # HTML5 모바일 웹 앱 구조
│  ├─ styles.css      # CSS3 모바일 우선 반응형 커스텀 스타일
│  └─ app.js          # Vanilla JS 상태 관리, 가격 축약 해석, 저장소 연동
├─ receipt.md         # 영수증 원문을 구매내역 JSON으로 변환하는 규칙
├─ history.md         # 버전별 변경 이력
├─ dev.md             # 개발 명세 및 운영 이력
├─ 구매내역.md        # 로컬 서버 실행 시 보조로 생성될 수 있는 런타임 파일
└─ README.md          # 프로젝트 문서
```
